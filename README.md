## Présentation

/kittycannon : lance un chat qui explose.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/kittycannon` | — | Lance un chat qui explose. | `shkittycannon.use` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shkittycannon.use` | Permet d'utiliser la commande /kittycannon. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/SHKittycannon/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
